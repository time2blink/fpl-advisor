# INSTALL / воспроизведение / перенос на другой компьютер

## Что нужно
- Python 3.8+ (python.org; при установке отметить «Add python.exe to PATH»). Дополнительных библиотек нет.
- Интернет (для API FPL: `https://fantasy.premierleague.com/api/…`, ключ не нужен).

## Отдать другу (Стасу, Роме)
1. Двойной клик по `tool/make_friend_pack.bat` (v1.16). Появится `dist/FPL_Advisor_for_friend.zip` — папка `dist` откроется сама. Отправь этот файл другу.
   Что делает скрипт (`tool/pack.py`): копирует `tool` **без** `cache/`, `out/`, `data/` (твоя история), `mock/`, `__pycache__/`, `claude_picks.json` (твой состав) и `FPL Advisor.lnk` (ярлык с твоим путём); в копии `config.json` очищает `pending`, `blacklist`, `watchlist` (`notes`, `entries`, `names`, `league_id` остаются — друг поменяет через ⚙). Твои файлы не трогает.
2. Другу — всё написано в `ПРОЧТИ_МЕНЯ.txt` в архиве: поставить Python 3.8+ (с галкой «Add python.exe to PATH»), распаковать, двойной клик по `FPL_Advisor/run.bat`. Первый расчёт покажет твою команду — нажать ⚙ рядом с названием команды, вписать **свой ID** и ID соперников (тебя и третьего), «Сохранить и пересчитать». Окно `run.bat` не закрывать, пока пользуется настройками.
3. Не собирается — запусти `py tool/pack.py` в консоли и пришли вывод Claude.

## Развернуть на новом компьютере
1. Скопировать папку `fpl-league-advisor` целиком (можно без `tool/cache/`, `tool/out/`).
2. Чтобы **сохранить историю** (снимки, тренды) — скопировать также `tool/data/fpl.db` (и при желании `tool/data/backup/`). Без него история начнётся заново (данные текущего момента всё равно загрузятся из API).
3. Проверить `tool/config.json`: ID менеджеров (`entries`), `league_id`, `pending` (если сделаны ходы на ближайший тур), `blacklist`. ID и лигу проще поменять в дашборде: ⚙ рядом с названием команды (v1.15).
4. Запустить `tool/run.bat` (или `py tool/fpl_tool.py`). Откроется `tool/out/dashboard.html`; файл для Claude — `tool/out/claude_brief.md`. Для ярлыка на рабочий стол — один раз `tool/create_shortcut.bat` (иконка в `tool/assets/`).
5. Автозапуск раз в день (необязательно): Планировщик заданий Windows → программа `py`, аргументы `fpl_tool.py --no-history`, рабочая папка `…\tool`.
   Если запуск кажется долгим или API отвечает 429 — подними `wide_min_minutes` в `config.json` (по умолчанию 90; например 270): история по турам будет качаться для меньшего числа игроков (v1.13).

## Как воспроизвести с нуля (если папку потеряли)
Скажи Claude: «прочитай CLAUDE.md и tool/CHANGELOG.md и воссоздай инструмент». Архитектура: `fpl_tool.py` (сеть+кэш → расчёт → SQLite → отчёты), `analytics.py` (план, соперники, цены, удача, гонка, экспорт), `probs.py` (v1.19: сила команд, CS %, DC %, голы/ассисты, стандарты, владение за 1/3/7 дней, тур вживую; таблицы `player_match`, `team_snap`), `dashboard_template.html` и `dashboard_template_v2.html` (два дизайна; данные подставляются вместо `/*__DATA__*/null`, общая логика из `dashboard_core.js` — вместо метки `__CORE__`), `config.json`, `run.bat`, `tests/make_mock.py` (демо-данные) и `tests/serve_mock.py` (фейковый API для проверки кэша без сети). Переменные окружения для тестов: `FPL_BASE`, `FPL_CACHE_DIR`, `FPL_DATA_DIR`, `FPL_OUT_DIR`.

## Файлы и что можно удалять
- `cache/` — кэш API, можно удалять когда угодно.
- `out/` — результаты, пересоздаются.
- `data/fpl.db` — история (не удалять, если нужна динамика); `data/backup/` — максимум 3 копии (само чистится); `data/fpl.db.corrupt-*` — отложенная повреждённая база (максимум 2), можно удалить.
- `mock/` — демо-данные для проверки.

## Типичные проблемы
| Симптом | Причина / решение |
|---|---|
| PowerShell 7 падает с `totalWidth must be non-negative` | Баг самого PowerShell (узкое окно). Запускать `run.bat`/cmd. |
| В cmd «’rlevel’ is not recognized» и кракозябры | `.bat` сохранён не в ASCII/CRLF. Использовать `run.bat` из репозитория. |
| Python не найден | Установить с python.org («Add to PATH»), открыть новый терминал, `py --version`. |
| Банк/FT/состав «на прошлый тур» | До дедлайна API не показывает новые трансферы. Вписать состав в `pending` в `config.json`. |
| `Не нашёл игрока 'X'` | В `pending`/`blacklist` писать как в FPL или `Имя:КЛУБ` (например `Thomas:COV`). |
| `Уже идёт другой запуск` | Подожди минуту или удали `data/.lock`. |
| `disk I/O error` на SQLite | База лежит на сетевом/смонтированном диске. Задать `FPL_DATA_DIR` на локальный диск. |
| База повреждена | Автоматически откладывается и восстанавливается из последней копии в `data/backup/`. |
| 429/ошибки сети | Программа ждёт и повторяет, при сбое берёт устаревший кэш; запускай позже или `--refresh`. |

## Откат базы вручную
Закрой программу, скопируй нужный `data/backup/fpl_ГГГГММДД.db` поверх `data/fpl.db`.
