# mobile/ — мобильный прототип FPL Advisor

Отдельный интерфейс под телефон (потом PWA/Capacitor → APK). Десктопный `tool/` не затронут. Без сборки, чистый JS.

## Экраны (5 вкладок)
- **Обзор** — шапка с дедлайном, «Сделай до дедлайна» (до 5 пунктов из данных), тур LIVE, вердикт Claude. До дедлайна сверху действия, после — ход тура.
- **Состав** — поле, скамейка, значок у игроков с заметкой Claude.
- **Ходы** — сегменты «Сейчас» (лучший ход + свёрнутые планы), «Топ-50» (что делают лучшие менеджеры мира), «Скаут».
- **Новости** — сводка Claude, цены (ожидаются / уже изменились), заметки. Источник — `news.json`.
- **Лига** — таблица, график, соперники.
- ⚙ **Настройки** (шестерёнка): ID, лига, соперники, что отслеживать, тема. Хранятся в localStorage.

## Данные
- `data.js` — срез из `tool/out/data.json`. Обновить: `python -X utf8 build_data.py` (после запуска `tool/run.bat`).
- `news.json` — заметки Claude. Формат: `{updated, summary, tags[], items:[{date, pid?, title, text}]}`. Адрес задан константой `NEWS_URL` в `app.js` (позже — raw-ссылка на GitHub).

## Макеты
`widgets.html` — макет виджетов (4×2, 2×2, 4×1) и уведомлений (за сутки, за 2 часа, всё готово, новость по игроку, тур идёт, экран блокировки). Генерируется скриптом из `index.html` и `app.js` (иконки-плитки те же).

## news.json
Кроме `summary`, `tags`, `items` содержит `todo` (список «Сделай до дедлайна» от Claude: `{k: ok|cap|warn|trade|price|chip|out, title, sub, go: squad|moves|news}`) и `decision` (`{title, text}` — решение на тур в «Ходах»). Если `todo` нет, показывается расчёт модели с пометкой.

## Запуск
`python -m http.server 8780 --bind 0.0.0.0 --directory mobile`, затем с телефона в той же сети: `http://<IP компьютера>:8780/`. При правках поднимать `?v=N` в `index.html`, иначе телефон держит кэш.

## Не сделано
Пуш-уведомления и виджет (нужен нативный слой), загрузка данных по ID из настроек (API FPL не отдаёт CORS), свой шрифт в пакете.
