# FPL Advisor

Бесплатный помощник по **Fantasy Premier League** (сезон 2026/27) для небольшой лиги друзей. Создан с помощью ИИ, лицензия [Apache 2.0](LICENSE).

> **Не аффилирован** с Premier League и официальной игрой Fantasy Premier League. Все данные берутся из открытого API fantasy.premierleague.com. Прогнозы — ориентир, а не гарантия результата.

## Для чего это

В Fantasy Premier League вы собираете команду из 15 реальных футболистов АПЛ и получаете очки за их игру. Проект решает конкретную задачу: **как стабильно занимать первые места в мини-лиге с друзьями**, где действует особое правило:

> **Игроки не могут повторяться между составами.** Если футболист есть у друга, вы его взять не можете.

Из-за этого лучшие по статистике игроки часто недоступны, и выигрывает тот, кто **раньше друзей находит сильные свободные альтернативы**. FPL Advisor отвечает на вопросы:

- Что сделать **до дедлайна** (трансферы, капитан, фишки)?
- Кто из моих игроков — слабое звено и кем его заменить в рамках бюджета и бесплатных трансферов?
- Кого у меня могут **перехватить друзья**, и кто из нужных игроков уже освободился?
- Что покупают и держат лучшие менеджеры мира (топ-50)?
- Как меняются цены и ожидаемые очки (xP) на ближайшие туры?

Решения принимает человек (в нашем случае — вместе с ИИ-ассистентом Claude, который проверяет новости: травмы, пресс-конференции, вероятные составы). Программа показывает картину и считает то, что можно посчитать по данным.

## Из чего состоит проект

| Часть | Что делает | Для кого |
|---|---|---|
| **Android-приложение** (`FPL Advisor`) | Короткий экран «что сделать до дедлайна», состав, ходы, новости, таблица лиги, виджет дедлайна | Для ежедневного использования с телефона |
| **Десктопный инструмент** (`tool/`, Python) | Качает API FPL, ведёт историю в SQLite, считает xP/план/угрозы, строит HTML-дашборд и файл-брифинг для ИИ | Для глубокого анализа перед дедлайном (Windows) |
| **Облачный конвейер** (GitHub Actions) | Раз в ~3 часа запускает тот же расчёт и публикует свежий срез данных | Питает приложение, ничего запускать не нужно |
| **Репозиторий данных** [`fpl-advisor-data`](https://github.com/time2blink/fpl-advisor-data) | Публичные `data.json`, `news.json`, `meta.json`, история снимков и **файлы APK в релизах** | Источник данных и обновлений приложения |

## Где скачать и как установить

### Android-приложение

1. Откройте на телефоне ссылку: **<https://github.com/time2blink/fpl-advisor-data/releases/latest/download/fpl-advisor.apk>** (файл `fpl-advisor.apk`, около 4,5 МБ). Страница релиза: <https://github.com/time2blink/fpl-advisor-data/releases/latest>.
2. Откройте скачанный файл. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разрешите: приложение распространяется не через Google Play.
3. Установите и запустите. Если Play Protect покажет предупреждение, это ожидаемо для приложений вне магазина (сборка подписана отладочным ключом).

Требования: **Android 7.0 (API 24) и новее**, интернет для загрузки данных.

**Обновления.** Приложение само проверяет, вышла ли новая версия (файл `version.json`), и показывает «Доступно обновление» с описанием изменений и кнопкой «Скачать». Вручную: ⚙ Настройки → «Проверить обновления». Историю версий видно в «Что нового».

### Десктопный инструмент

Работает на **Windows** (есть `run.bat`), требуется **Python 3.8+** (при установке с python.org отметьте «Add python.exe to PATH»). Сторонних библиотек ставить не нужно, ключи и регистрация не требуются.

- **Из репозитория:** папка [`tool/`](tool/) — это и есть инструмент. Скачайте репозиторий (**Code → Download ZIP**) или `git clone https://github.com/time2blink/fpl-advisor.git`, затем работайте в папке `tool/`.
- **Архивом для друга:** `tool/make_friend_pack.bat` собирает `dist/FPL_Advisor_for_friend.zip` (инструмент без вашей истории и личных списков) с файлом `ПРОЧТИ_МЕНЯ.txt`.
- **Попробовать без сети (демо):** `python tool/tests/make_mock.py`, затем `python tool/fpl_tool.py --offline`.

Запуск: двойной клик по `tool/run.bat`. Примерно через 30 секунд дашборд откроется по адресу `http://127.0.0.1:8765/dashboard.html`. В `config.json` стоят **условные ID** (1000001 и т. д.) — реальных данных нет, поэтому сначала нажмите ⚙ рядом с названием команды и впишите **свой ID** и ID соперников (см. [ниже](#как-узнать-свои-id)).

## Android-приложение

Интерфейс на русском. Пять вкладок и настройки:

| Вкладка | Что показывает |
|---|---|
| **Обзор** | Шапка с дедлайном и счётчиком времени, блок «Сделай до дедлайна» (до 5 пунктов: капитан, трансферы, цены, фишки, игроки под вопросом), во время тура — ход игры (LIVE) и «вердикт» ассистента |
| **Состав** | Поле с расстановкой, скамейка, значок у игроков с заметкой ассистента |
| **Ходы** | «Сейчас» — лучший ход и планы на несколько туров; «Топ-50» — что делают лучшие менеджеры мира; «Скаут» — список наблюдения (кого купить, когда освободится) |
| **Новости** | Сводка, ожидаемые и уже случившиеся изменения цен, заметки по игрокам |
| **Лига** | Таблица мини-лиги, график, соперники |
| **⚙ Настройки** | Аккаунт, лига, соперники, что отслеживать, тема оформления, справка |

Также есть **виджет дедлайна** на рабочем столе и переход в нужный раздел по тапу. Карточка игрока показывает форму, ближайших соперников со сложностью, очки по прошлым турам, шансы (чистый лист, гол, ассист) и исполнителей стандартов.

## Настройки приложения: что в какое поле вписывать

Откройте ⚙ в правом верхнем углу. Настройки хранятся **на устройстве** (в памяти приложения), на сервер ничего не отправляется.

### Как узнать свои ID

| Что | Где взять |
|---|---|
| **ID менеджера** | Войдите на fantasy.premierleague.com → вкладка «Points» / «Очки». В адресе: `fantasy.premierleague.com/entry/`**`1234567`**`/event/8` — число после `entry/` и есть ваш ID |
| **ID лиги** | Fantasy → «Leagues & Cups» → откройте нужную лигу. В адресе: `…/leagues/`**`1234567`**`/standings/c` — число после `leagues/` |

Номера — только цифры, без пробелов и символов.

### Поля

| Раздел / поле | Что вписать | Допустимые значения и ошибки |
|---|---|---|
| **Мой аккаунт → Имя** | Как вас называть в интерфейсе (например «Женя») | Любой текст |
| **Мой аккаунт → Мой ID в FPL** | Ваш ID менеджера | Только цифры. Иначе: «ID — только цифры» |
| **Лига → ID лиги** | ID вашей мини-лиги | Только цифры |
| **Соперники → Имя** | Как подписать соперника | Обязательно: «Укажи имя» |
| **Соперники → ID менеджера** | ID соперника (так же, как свой) | Только цифры; одинаковые ID нельзя («Этот ID уже есть») |
| **Соперники** (кнопки) | «Добавить соперника» / ✕ | От 1 до 5 соперников |
| **Топ мира** | Чьи составы разбирать для экрана «Топ-50» | Топ-10, Топ-30 или Топ-50 |
| **Что отслеживать** | Переключатели уведомлений (см. ниже) | Вкл / выкл |
| **Оформление** | Тема | Система, Светлая, Тёмная |
| **Справка** | «Показать пример уведомления», «Справка по терминам», «Что нового», «Проверить обновления» | — |
| **Сохранить / Сбросить к умолчаниям** | Применить или вернуть исходные значения | — |

**Переключатели «Что отслеживать»:** *Дедлайн* (за сутки и за 2 часа), *Травмы и возвраты* (ваши игроки и скаут-лист), *Изменения цен* (ваши игроки и скаут-лист), *Ходы соперников*, *Новости Claude* (вердикт и заметки).

> ⚠ **Важно:** в текущей версии данные приложения собираются облачным конвейером для **конкретной лиги владельца проекта**. Настройки ID сохраняются локально и подписи/оформление уже работают, но полноценная загрузка *вашей* команды по введённому ID (API FPL не отдаёт CORS-заголовки браузерам) — в планах. Для анализа **своей** лиги сегодня используйте десктопный инструмент.

## Десктопный инструмент (Windows)

### Что получаете после запуска

- `out/dashboard.html` — интерактивный дашборд (открывается автоматически);
- `out/claude_brief.md` — текстовый брифинг для ИИ-ассистента: составы, банк, FT, цены продажи, рейтинги, xP, план, ходы топ-50, угрозы, изменения за период;
- `out/data.json`, `out/export/*.csv` (игроки, ваш состав, план, угрозы — для Excel), `out/run.log`;
- `data/fpl.db` — история ежедневных снимков (цены, владение, форма) в SQLite.

### Запуск

| Способ | Что происходит |
|---|---|
| Двойной клик по `run.bat` | Обновляет данные, открывает дашборд, **держит локальный сервер 127.0.0.1**, пока открыто чёрное окно (нужно для ⚙ настроек и пересчёта из браузера). Закрыли окно — в фоне ничего не остаётся |
| `python fpl_tool.py` | Один расчёт и выход (подходит для планировщика заданий) |
| Ярлык | `create_shortcut.bat` создаёт на рабочем столе «FPL Advisor» |

Параметры командной строки:

| Параметр | Действие |
|---|---|
| `--no-history` | Быстрее: не качать историю игроков по турам |
| `--refresh` | Игнорировать кэш, перекачать всё |
| `--offline` | Демо на данных из `mock/`, без сети |
| `--serve` | После расчёта держать дашборд с настройками на 127.0.0.1 (его включает `run.bat`) |
| `--no-open` | Не открывать браузер |
| `--config <путь>` | Использовать другой `config.json` |

Переменные окружения (для тестов и облака): `FPL_BASE`, `FPL_CACHE_DIR`, `FPL_DATA_DIR`, `FPL_OUT_DIR`, `FPL_CONFIG`, `FPL_NO_OPEN`.

### Вкладки дашборда (Дизайн 2, светлый)

Обзор · Состав · Трансферы и план · Скаут-лист · Игроки · Матчи · Соперники и лига · Рынок · Топ-50 · Изменения.

- **Обзор** — вердикт по трансферам, ключевые цифры, фишки, внимание, ближайший план, лучшие ходы.
- **Состав** — рекомендованный состав на тур (11 + скамейка, капитан, вице) и расчёт программы по xP.
- **Трансферы и план** — слабые звенья с запасными вариантами, лучшие одиночные и двойные ходы, **план на 8 туров** с хитами и фишками, пары для ротации вратарей и защитников.
- **Скаут-лист** — игроки под наблюдением по приоритетам P1–P3, фильтры «Все / Мои / От ассистента», добавление игрока.
- **Игроки** — поиск и рейтинг; переключатель «Весь рынок» добавляет всех, кто сыграл от `wide_min_minutes` минут; вид «Шансы на тур» (CS %, DC %, гол, ассист, стандарты).
- **Матчи** — календарь команд на 5–10 туров (CS % / xG / xGA / сложность), исполнители стандартов по клубам.
- **Соперники и лига** — тур вживую, мини-лига, вероятные ходы друзей, угроза перехвата ваших целей, владение в лиге, «чёрный список», гонка за первое место, точность прогноза (бэктест).
- **Рынок** — давление на цены, удача/перегрев, кто набирает владение за 24 ч / 3 / 7 дней.
- **Топ-50** — что покупают и держат лучшие менеджеры мира.
- **Изменения** — что изменилось с прошлого снимка.

Наведите курсор на подчёркнутый заголовок колонки, значок «?» или цветную метку — появится пояснение. Клик по имени или аватару игрока открывает **карточку игрока**: цифры, следующие матчи со сложностью и xP, очки в прошлых турах, прошлые сезоны, шансы по турам.

**Два дизайна:** «Дизайн 2» (светлый, по умолчанию) и «Дизайн 1» (классический). Переключение: ⚙ Настройки → «Дизайн дашборда» или `config.json → "design": 1 | 2`.

### ⚙ Настройки в дашборде

Кнопка ⚙ справа от названия команды на вкладке «Обзор»:

| Поле | Что вписать |
|---|---|
| **Мой ID** | Ваш ID менеджера (число из адреса страницы «Очки») |
| **Соперники** | От 1 до 5: ID + имя (пустое имя подтянется из FPL) |
| **ID мини-лиги** | Необязательно; даёт таблицу лиги |

Каждый ID сразу проверяется в FPL. «Сохранить и пересчитать» пишет `config.json` (прежняя версия — в `data/config_history`, хранятся 5 последних). **Работает только при запуске через `run.bat`** (адрес 127.0.0.1); если открыть `dashboard.html` как файл — это режим просмотра.

### Как вводить ходы, пока дедлайн не прошёл (`pending`)

API FPL **скрывает трансферы на ближайший тур до дедлайна**. Поэтому, если вы уже сделали ходы, впишите итоговый состав вручную в `config.json → pending`:

```json
"pending": {
  "me": {
    "gw": 9,
    "squad": ["Raya:ARS", "Gabriel:ARS", "... всего 15 игроков ..."],
    "captain": "Haaland",
    "vice": "Isak",
    "bank": 5,
    "ft": 0
  }
}
```

| Поле | Значение |
|---|---|
| `me` / `stas` / `roma` (ключи совпадают с ключами `entries`) | Чей это состав. Для соперников заполняйте, если знаете их ходы |
| `gw` | **Номер тура**, на который введён состав. После дедлайна этого тура блок автоматически игнорируется (с предупреждением) и берётся состав из API |
| `squad` | 15 игроков. Имя — как в FPL; при неоднозначности `Имя:КЛУБ` (например `Thomas:COV`) |
| `captain`, `vice` | Капитан и вице-капитан |
| `bank` | Банк **в десятых**: `3` = £0.3m, `24` = £2.4m |
| `ft` | Свободные трансферы на тур |

## Настройки инструмента: `config.json`

Файл `tool/config.json`. Менять можно любым текстовым редактором (сохраняйте валидный JSON — кавычки и запятые). Часть значений удобнее менять в ⚙ дашборда.

### Аккаунты и лига

| Ключ | Пример | Что означает |
|---|---|---|
| `season` | `"2026/27"` | Сезон (информационно) |
| `entries` | `{"me": 1234567, "friend1": 2345678}` | **ID менеджеров**: ключ — короткое имя, значение — число. Ключ `me` — вы |
| `names` | `{"me": "Женя", "friend1": "Стас"}` | Отображаемые имена. Ключи — те же, что в `entries` |
| `league_id` | `1234567` | ID мини-лиги (можно `null`) |
| `rule_no_duplicates` | `true` | Пометка правила лиги «без повторов» (расчёт доступности игроков идёт по составам соперников независимо от флага) |

### Расчёт и рекомендации

| Ключ | По умолчанию | Что означает |
|---|---|---|
| `pool` | `{"GK":10,"DEF":50,"MID":50,"FWD":20}` | Размер списков кандидатов по позициям, из которых строятся **рекомендации**. Больше — шире поиск, но дольше расчёт |
| `top_managers` | `50` | Сколько лучших менеджеров мира анализировать (ходы, капитаны, владение) |
| `horizon` | `5` | Горизонт xP в турах (xP5 — сумма на 5 туров) |
| `planner_horizon` | `8` | Горизонт плана трансферов в турах |
| `min_minutes_frac` | `0.25` | Минимальная доля сыгранных минут, чтобы игрок попал в рекомендации (меньше — «не основа») |
| `wide_min_minutes` | `90` | Порог минут за сезон для режима «Весь рынок»: для всех, кто сыграл от этого числа, качается история по турам и работает поиск. Больше (например 270) — быстрее запуск. На рекомендации **не влияет** |
| `prior_k` | `4` | Вес прошлого сезона в xP: `K/(n+K)`, где n — число выходов на поле в этом сезоне. `0` — выключить |
| `max_free_transfers` | `5` | Максимум накопленных бесплатных трансферов |
| `hit_cost` | `4` | Штраф за платный трансфер (хит) |
| `max_hits_per_gw` | `1` | Максимум хитов за тур в плане |
| `deny_weight` | `0.3` | Вес «блокировки»: бонус за покупку цели, которую хотят забрать друзья. `0` — выключить |
| `weak_include_bench` | `false` | Считать ли игроков скамейки «слабыми звеньями» |
| `free_transfers_override` | `null` | Принудительно задать число FT, если расчёт не совпал с приложением FPL |
| `bank_override` | `null` | Принудительно задать банк (в десятых), если расчёт не совпал |

### Фишки

| Ключ | По умолчанию | Что означает |
|---|---|---|
| `chip_halves` | `true` | Два набора фишек за сезон |
| `chip_reset_gw` | `20` | С какого тура открывается второй набор |
| `chip_expiry_gw` | `19` | Тур, после дедлайна которого сгорает первый набор |
| `chip_expiry_deadline` | `"2027-01-02T13:30:00Z"` | Точное время этого дедлайна (UTC) |

### Работа программы

| Ключ | По умолчанию | Что означает |
|---|---|---|
| `design` | `2` | Дизайн дашборда: `2` светлый, `1` классический |
| `serve_port` | `8765` | Порт локального сервера (127.0.0.1) |
| `retention_days` | `90` | Снимки старше этого срока прореживаются до одного в неделю |
| `notes` | — | Комментарии к файлу (программа их не использует) |

### Списки

| Ключ | Формат | Что означает |
|---|---|---|
| `blacklist` | `["Имя:КЛУБ", …]` | Игроки, которых **нельзя рекомендовать** (например, забрал друг). Игроки из составов соперников исключаются автоматически. Для слежения за освобождением: `"Cherki:MCI@friend1"` или `{"player":"Cherki:MCI","owner":"friend1","pin":false}` |
| `watchlist` | `[{"player":"Имя:КЛУБ","prio":1,"note":"…","trigger":"…"}]` | **Скаут-лист**: `prio` 1–3 (1 — самый важный), `note` — почему следим, `trigger` — при каком условии действовать. Записи с `"source":"user"` добавлены вручную в дашборде |
| `pending` | см. выше | Ручной состав/банк/FT до дедлайна |

### Рекомендация ассистента: `claude_picks.json`

Необязательный файл, который ведёт ИИ-ассистент: `gw` (тур), `updated`, `status` (насколько проверены новости), `formation`, `xi` (11 игроков), `bench` (4 по порядку автозамены, первым вратарь), `captain`, `vice`, `summary`, `notes` (пояснения по игрокам), `tags` (3–5 коротких фактов). Дашборд показывает его во вкладке «Состав» и берёт из него капитана; если файл относится к другому туру или не совпадает с текущими 15 игроками, будет предупреждение.

## Как читать цифры: словарь терминов

| Термин | Расшифровка |
|---|---|
| **GW** | Gameweek, игровой тур. GW9 — девятый тур |
| **Дедлайн** | Время, после которого трансферы и состав на тур закрыты |
| **FT** | Free Transfer, бесплатный трансфер. Копятся (до `max_free_transfers`) |
| **Хит** | Платный трансфер сверх FT: −4 очка за каждый |
| **Банк** | Свободные деньги, £ млн (в `config.json` — в десятых) |
| **Цена продажи** | Цена покупки + половина прибыли (с округлением вниз), как в FPL |
| **Чипы / фишки** | Wildcard (WC), Free Hit (FH), Bench Boost (BB), Triple Captain (TC). Два набора за сезон; первый нужно сыграть до дедлайна GW19, второй открывается с GW20 |
| **xP** | Expected Points — ожидаемые очки. xP1 — на ближайший тур, xP5 — за 5 туров. Эвристика: очки/игру и форма с поправкой на сложность матча, вероятность выйти на поле, доступность и прошлый сезон. **Не знает про новости** |
| **Рейтинг 0–100** | Оценка игрока внутри позиции (очки, форма, xGI, календарь, минуты, очки за £) |
| **CS %** | Clean Sheet — шанс «сухого» матча (по xG команд, Пуассон) |
| **DC %** | Defensive Contribution — шанс набрать порог защитных действий (10 у защитников, 12 у остальных) |
| **xG / xA / xGI / xGC** | Ожидаемые голы / ассисты / голы+ассисты / пропущенные |
| **Стандарты** | Пенальти, штрафные, угловые и номер в очереди исполнителей |
| **Сложность FPL** | Оценка матча 1–5 (1–2 лёгкий, 3 средний, 4 сложный, 5 тяжёлый) |
| **Ownership / владение** | Доля менеджеров, у которых есть игрок |
| **Давление на цену** | Оценка, куда пойдёт цена по чистому потоку трансферов |
| **Перехват / угроза** | Вероятность, что друг заберёт игрока, которого вы наметили |
| **Бэктест** | Проверка прогноза: пересчёт по данным до тура и сравнение с фактом (MAE — средняя ошибка; чем меньше, тем лучше) |

Формула xP (упрощённо): `(0.7·(0.5·очки/игру + 0.5·форма) + 0.3·среднее по позиции) × поправка на сложность (+10% за уровень ниже 3) × вероятность выйти на поле × доступность`, суммируется по матчам ближайших туров; двойные туры учитываются, отсутствие матча = 0.

## Откуда данные и как часто они обновляются

| Источник | Что даёт | Обновление |
|---|---|---|
| **API FPL** (`fantasy.premierleague.com/api`) | Цены, форма, очки, владение, флаги травм, календарь, составы/банк/трансферы менеджеров **до последнего дедлайна**, ходы топ-50 | Кэш: составы друзей 5 мин, общие данные 10 мин, топ-50 1 час, календарь 6 ч, история игроков 12 ч |
| **Ввод вручную** (`pending`) | Составы/банк/FT на ближайший тур, пока API их скрывает | По мере изменений |
| **Новости** (поиск ассистентом) | Травмы, пресс-конференции, вероятные составы, сроки возвратов — **в API их нет** | Перед каждым решением; результат в `news.json` и `claude_picks.json` |
| **Облачный конвейер** | Свежий срез для приложения | Каждые ~3 часа (GitHub Actions, cron `7 */3 * * *`) |

Нагрузка на API щадящая: до ~8 запросов в секунду, 4 потока, при ответе 429 программа ждёт и повторяет; при недоступности сети берёт устаревший кэш и предупреждает.

Для мобильного интерфейса срез собирается командой `python -X utf8 mobile/build_data.py` после расчёта в `tool/`. Упоминания имён друзей в документации — примеры из исходной лиги.

## Ограничения

- Прогнозы (xP, план, шансы, ходы друзей, давление на цены) — **модель по статистике**, а не факт. В API нет вероятных составов и пресс-конференций, поэтому важные решения нужно сверять с новостями.
- Ходы на ближайший тур до дедлайна API не показывает — вносите их в `pending`.
- Сейчас приложение показывает данные одной конкретной лиги (см. предупреждение в разделе настроек).
- APK собран как отладочный (debug) и не опубликован в Google Play.
- Проект неофициальный и не связан с Premier League.

## Частые проблемы

| Симптом | Решение |
|---|---|
| Python не найден | Установите с python.org с галкой «Add to PATH», откройте новый терминал, проверьте `py --version` |
| Банк/FT/состав «на прошлый тур» | До дедлайна API не показывает новые трансферы — заполните `pending` |
| `Не нашёл игрока 'X'` | Пишите имя как в FPL или `Имя:КЛУБ` (например `Thomas:COV`) |
| `Уже идёт другой запуск` | Подождите минуту или удалите `data/.lock` |
| `disk I/O error` | База лежит на сетевом диске — задайте `FPL_DATA_DIR` на локальный диск |
| Ошибка 429 / нет сети | Программа ждёт и повторяет, берёт кэш. Запустите позже или с `--refresh` |
| База повреждена | Автоматически откладывается и восстанавливается из `data/backup/` (хранятся 3 копии) |
| Запуск долгий | Поднимите `wide_min_minutes` (например 270) или запускайте с `--no-history` |
| ⚙ в дашборде не сохраняет | Страница должна быть открыта через `run.bat` (адрес 127.0.0.1), а не как файл |
| Приложение не ставится | Разрешите установку из неизвестных источников для браузера/«Файлов»; нужен Android 7.0+ |
